# Car Rental System

A full-stack Car Rental Management System built using Java Servlets, JSP, JDBC and MySQL.

## Features

- User Registration & Login
- Car Booking
- Return Car Workflow
- Maintenance Tracking
- Late Fee Calculation
- Session Management
- Responsive Success UI
- MySQL Database Integration

## Tech Stack

- Java
- JSP
- Servlets
- JDBC
- MySQL
- HTML
- CSS
- Apache Tomcat

## Setup

1. Clone repository
2. Import into VS Code/Eclipse
3. Configure MySQL
4. Deploy using Apache Tomcat
5. Run application
